# Shop media provenance

Representative imagery for EIKON seed products. Every file below was
verified public domain (or CC0) via Wikimedia Commons extmetadata at
fetch time by scripts/fetch-shop-media.mjs. `image_is_representative`
stays true on every seed product until real supplier product photos exist.

Some covers are auto-oriented (EXIF) and cropped by a fractional inset
recorded in each product's `media.crop` in data/shop/seed-products.json, so
that a caption band, titulus, or museum frame is trimmed off the storefront
card. Re-running fetch-shop-media.mjs reproduces the same crop.

Note: st-nicholas-wooden-icon.jpg and anastasis-pascha-icon.jpg were
re-sourced on 2026-07-13 to cleaner single-figure images (the prior sources
carried dense inscription bands and rows of border saints).
