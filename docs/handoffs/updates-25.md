## Gotchas

- **checkMock is fast on long pages now**; before, any screen with hundreds of icons ran past a walk's limit. `docs/handoffs/updates-21-walks/touched-check.mjs` closes the page under a measure after `--limit` seconds (150 by default): a "Target page, context or browser has been closed" there is the limit, not the page.
- **To judge one tap old and new without a second export:** `docs/handoffs/updates-25-walks/rejudge.mjs <dump.json ...>` judges saved recordings with an old `frames.mjs` (`OLD_FRAMES=<its path>`, a checkout of the old code) and the current one. Recordings are saved by a copy of `scripts/motion-walk.mjs` with two lines added (in `recordAct`, write `{ name, rec }` to a file when the control's name matches; before the tap, `globalThis.__dumpName = c.name`).
- **The other probes** (`docs/handoffs/updates-25-walks/`): `probe-next.mjs <out> <page> [still]` records a work's "Next" with the gate's recorder and judge (two runs; add a scroll before the tap for a chapter's foot); `probe-profile.mjs <out> [name]` prints the profile card's rect, layout height and styles frame by frame, and the layout shifts; `probe-rail.mjs <out>` runs the stripe measure on an opened thread. Each imports by full path from `/home/user/purifyapp`.
- **The export from a worktree:** `git worktree add --detach <dir> HEAD`, `cp -al node_modules`, then `node scripts/gate/export.mjs` there: the main checkout stays free for edits, tests and the web build. A full export took about 2 minutes 15 seconds.
- **The glide measure's weak spot:** it follows parts that move up or down only (the glides in a page do). A sideways glide that the old rule called a cut still is one.
- A fresh container has no `node_modules`: `npm ci`, then `npx next typegen` before the typecheck.
