# 1.7 announcements

The words that go out are in `drop.json` beside this file, written out as
`drop.md`: the stores' texts, the Discord posts, the board, the letter, the
notification and the captions, each in the order it goes. Start it once the
note is written:

    node scripts/drop.mjs new 1.7

The owner posts and sends everything. docs/DROP.md says how a drop works.
Notes that belong to no piece go below.
