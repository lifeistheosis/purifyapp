# The iPhone store pictures at 1179 by 2556

Made on 2026-11-20 by Arbiter 15 for App Store Connect's "iPhone with Dynamic Island (medium display)" slot, which refused the 6.9 inch set with "File dimensions are invalid" (his screenshot, 17:11 UTC).

**They are resized copies, not a retake.** Each is `../appstore-iphone-6.9-NN-*.png` (the set of 2026-11-12) converted to full colour, scaled to 1179 wide (Lanczos) and cut by six pixels of height, three at the top and three at the bottom.

**Apple's sizes that day** (its screenshot specifications page, read 2026-11-20):

- iPhone with Dynamic Island (medium display): 1179 x 2556 or 1206 x 2622.
- iPhone with Dynamic Island (large display): 1260 x 2736, 1290 x 2796 or 1320 x 2868. The 6.9 inch set fits here.
- iPad 13 inch: 2064 x 2752 or 2048 x 2732.
- iPhone Duo: 1398 x 2034 (outer) and 2007 x 2853 (inner), required from April 2027 for apps on the iOS 27.1 SDK.
